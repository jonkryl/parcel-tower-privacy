# Parcel Tower — privacy policy

Статическая политика конфиденциальности игры «Башня посылок / Parcel Tower» от **SamokrylTeam**, на русском и английском языках.

Источник страницы: [index.html](index.html). Внешних скриптов, SDK и счётчиков нет.

Планируемый адрес после настройки и успешной публикации GitHub Pages: [https://jonkryl.github.io/parcel-tower-privacy/](https://jonkryl.github.io/parcel-tower-privacy/).

Для публикации выбрать **Settings → Pages → Source: GitHub Actions**. Workflow запускается при push в `main` или вручную и публикует только `index.html` через официальные GitHub Pages actions; пользовательские секреты не требуются.

Контакт по вопросам политики и удаления данных: [jonkryl@gmail.com](mailto:jonkryl@gmail.com).
